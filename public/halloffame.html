Security Vulnerability & Bug Bounty Policy

Official terms for technical vulnerability reporting on AcademicLevel.

Zero Public Recognition Policy

Please note: You will receive NO public recognition, NO Hall of Fame listing, NO certificates, NO website shoutouts, and NO public acknowledgments whatsoever for reporting any bugs. All legacy recognition pages have been permanently taken down.

Bounty Reward: ₹10 Amazon Gift Card (Amazon GC)

If you discover and responsibly report a genuine security vulnerability that our engineers verify to be VERY VERY VERY VERY critical, you are eligible to receive a ₹10 Amazon Gift Card (Amazon GC) sent to your email after technical verification.

What Qualifies (Must be VERY Critical)

  • Remote Code Execution (RCE) directly compromising production server host or containers.
  • Direct SQL / Database Injection resulting in unauthenticated total production data compromise.
  • Full Server-Side Auth Bypass allowing complete unauthorized control of the Super-Admin Vault.

What Does NOT Qualify (Zero Bounty)

  • Missing HTTP security headers (CSP, HSTS, X-Frame-Options, etc.).
  • Rate-limiting timing quirks, public assets, or local storage inspection.
  • SPF, DKIM, or DMARC email record observations.
  • Automated scanner or pentest tool outputs without a proven functional exploit.
  • Minor copy, UI glitches, or expected client-side features.

How to Submit a Report

Send a complete proof of concept (PoC), step-by-step reproduction steps, and HTTP request logs to:

securityacademiclevels@gmail.com

Rules of Engagement: Do not exfiltrate or modify student records, do not perform DoS/DDoS attacks, and do not disclose details publicly prior to coordinated resolution.

Bounty terms: Exactly one ₹10 Amazon Gift Card (Amazon GC) strictly for verified VERY VERY VERY VERY critical vulnerabilities.
